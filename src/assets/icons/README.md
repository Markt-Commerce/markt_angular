# Markt App Icons

This directory contains the icon files for the PWA manifest using the actual Markt branding.

## Current Icons:
- `icon-192x192.png` - 192x192 pixels (Markt Logo)
- `icon-512x512.png` - 512x512 pixels (Markt Logo)
- `notification-icon.png` - For push notifications (Markt Logo)
- `badge-icon.png` - For notification badges (Markt Logo)

## Source:
All icons are based on the Markt logo from `/public/Logo.png` which is used throughout the application.

## Design Guidelines:
- Uses Markt brand colors (#e85530 primary, #d14520 secondary)
- Consistent with the logo used in the application header
- Works well in both light and dark themes
- Proper padding for maskable icons
